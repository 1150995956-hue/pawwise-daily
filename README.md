# Pawwise Daily

A mobile-friendly educational website about practical, kind dog and cat care.

## Pages
- Home: `index.html`
- Dog care guide: `dog-care.html`
- Cat care guide: `cat-care.html`
- About: `about.html`
- Privacy: `privacy.html`
- Terms and veterinary disclaimer: `terms.html`

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save. Wait for the deployment status to complete.

Expected website address:
https://1150995956-hue.github.io/pawwise-daily/

## Important
This site provides general educational information, not veterinary diagnosis or treatment. Review all content before publication. The privacy and terms pages describe the current simple static site and should be updated if analytics, advertising, contact forms, or other third-party services are added.
